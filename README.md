# Clocktower Studio para Android

[Descargar Clocktower-Studio.apk](https://github.com/segundocires/clocktower-studio-downloads/releases/latest/download/Clocktower-Studio.apk)

Versión inicial de prueba 0.1.0. Requiere Android 7.0 o posterior. El APK universal ocupa aproximadamente 86 MiB y funciona sin Metro ni herramientas de desarrollo en el teléfono.

## Instalar

1. Abrí el enlace de descarga desde el teléfono.
2. Abrí el APK descargado. Si Android lo solicita, permití a tu navegador instalar esta aplicación y confirmá la instalación.
3. Abrí Clocktower Studio. Para sincronizar proyectos y referencias, emparejá el teléfono con el servidor Clocktower de tu PC mediante su QR o código temporal, con ambos equipos en la misma red.

## Actualizaciones

La app consulta las nuevas versiones al abrirse y mediante tareas periódicas de Android. Descarga automáticamente por Wi-Fi sin límite de datos. Cuando una actualización esté lista, pulsá **Instalar actualización** y confirmá en Android. Las restricciones de batería o una detención forzada pueden aplazar las consultas en segundo plano.

Cada actualización comprueba tamaño, SHA-256, versión, identificador de aplicación y la misma firma que la app instalada. La publicación incluye `latest.json`, `apk.sha256` y `apk-metadata.json`.

## Estado de esta versión

Compilación, firma y descarga pública verificadas. La prueba de instalación, cámara, galería y actualización entre dos versiones en un teléfono físico queda pendiente. El instalador de escritorio Windows también está pendiente; el servidor y el escritorio web se ejecutan desde el proyecto local.

Este repositorio distribuye instaladores y metadatos. No contiene proyectos, fotografías, credenciales ni la clave privada de firma.
